# 文風指南（canon v0.1 草案）

- 繁體中文，節制、自然；視角限於韓敬所知。
- 以工作呈現制度：填數、等候、退件、署字、收冊。解釋制度只在讀者需要理解他的選擇時。
- 禁：現代術語與後設語；每場戲後解釋主題；血、鐵、深淵等強烈意象連用；握拳咬唇表決心。
- 對話：允許答非所問、半句話、誤判、自欺；不寫成論文摘要。
- 人物稱呼：官稱用明初語境；層級用語：六月甲午前「行省」，後「布政使司」，人物口中可新舊並用（FA-07，不作情節承重）。
- 禁用詞：磨勘、計簿、報冊（作戶部考校名）；黃冊；不引《大明律》條號。
- 敘述者不替「冤」之說背書。「冤」是人物的說法。
- 句長錯落；場景結尾不總結。
- 正文不得殘留任務編號、道具代碼、章節製作說明。「編輯附註」另置，匯出時排除。
